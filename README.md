# GW Luxury

Chauffeur-driven motor cars in Lagos. Driver and fuel included. Dispatched to your pickup address.

## Fleet (12-hour rates)

- Mercedes-Benz G-Class 2022 — NGN 1,000,000
- Cadillac Escalade — NGN 650,000
- Toyota Land Cruiser Prado 2020 — NGN 150,000 (Island & Airport)

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Inbox

House requests live at [http://localhost:3000/admin](http://localhost:3000/admin).

Set `ADMIN_PASSWORD` in `.env.local`. In development the fallback password is `orangered`. Production will not start the inbox without the env var. The inbox is not linked from the public site.
